## 2. How would you track a production performance issue?

1. Check monitoring dashboards.
2. Analyze application logs.
3. Review slow database queries.
4. Profile API response times.
5. Check server resources (CPU, Memory).
6. Reproduce issue in staging.

At CtrlS, I optimized a dashboard API handling millions of records by introducing proper indexing, query tuning, and caching, reducing response time from ~30 seconds to under a second.
