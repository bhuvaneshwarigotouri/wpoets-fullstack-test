# WPoets Full Stack Developer Test

## Tech Stack
- PHP 8+
- MySQL
- HTML5
- CSS3
- Bootstrap 5
- jQuery
- Slick Slider

## Features
- CRUD Operations
- Dynamic Tabs/Accordion
- Synced Content Slider & Image Slider
- Responsive Design
- Mobile Accordion View
- MySQL Database Integration

## Setup

1. Import database/schema.sql
2. Configure database credentials in config.php
3. Run project using Apache/XAMPP
